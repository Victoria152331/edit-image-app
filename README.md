# Browser Image Enhancer

Небольшой браузерный проект для автоматического улучшения изображений с помощью ML-модели.

Пользователь загружает изображение, модель предсказывает параметры коррекции, после чего изображение автоматически улучшается по трём характеристикам: brightness (яркость), contrast (контрастность) и saturation (насыщенность цвета).

Вся обработка выполняется прямо в браузере без серверной части. Изображение никуда не отправляется — это одновременно упрощает архитектуру и избавляет от проблем с хранением пользовательских файлов.

## Как это работает

Основная идея простая:

1. Пользователь загружает изображение.
2. Изображение передаётся в Web Worker.
3. Worker запускает ML-модель.
4. Модель предсказывает коэффициенты для brightness / contrast / saturation.
5. Алгоритм применяет коррекцию к каждому пикселю.
6. Готовое изображение возвращается в основной поток.

Во время обработки интерфейс не блокируется — пользователь может продолжать взаимодействовать со страницей.
Для этого вся тяжёлая работа вынесена в отдельный поток через Web Worker.

Worker регулярно отправляет прогресс обработки обратно в основной поток, поэтому UI может показывать статус выполнения в реальном времени.

## Почему модель запускается в браузере

Проект специально сделан полностью client-side.

Это даёт несколько плюсов: изображения не загружаются на сервер, не нужна серверная инфраструктура, обработка работает асинхронно, а приложение можно запускать как статический сайт.

Но есть и ограничение: модель должна быть достаточно лёгкой, чтобы работать прямо в браузере пользователя.

## API

Основная логика вынесена в модуль `ImageEnhancer`. Он создаёт задачи обработки, хранит их список, позволяет получать инфоррмацию и отменять задачи по идентификатору. Для каждой задачи хранится её идентификатор, статус, результат обработки и экземпляр worker.

### Методы

#### `submit(file)`

Создаёт задачу обработки, запускает worker и передаёт ему данные изображения.

#### `getStatus(taskId)`

Возвращает текущий статус и прогресс:

```js
{
  status: 'processing',
  progress: 42
}
```

Поддерживаются статусы: `pending`, `processing`, `done`, `error`, `cancelled`.

#### `getResult(taskId)`

Возвращает результат обработки после завершения задачи в формате canvas.

#### `cancel(taskId)`

Прерывает выполнение задачи и завершает worker.

## События

API построен на `EventTarget`, поэтому UI можно обновлять через события без постоянного polling.

```js
onStatusChange = (e) => {
    console.log(e.detail);
};

ImageEnhancer.addEventListener('statusChange', onStatusChange);
```

## Поддерживаемые форматы

Вход и выход поддерживают форматы JPG, PNG, BMP и HEIC.

Для работы с HEIC используются дополнительные библиотеки, так как формат не поддерживается в браузерах по умолчанию.
Кодирование HEIC файл довольно тяжёлая операция, поэтому для экспорта HEIC в проекте реализован отдельный Web Worker.

### Основные файлы

`main.js` — UI и работа с API;
`api-module.js` — управление задачами;
`ImageWorker.js` — запуск ML-модели и обработка изображения;
`heicWorker.js` — экспорт HEIC;
`model/` — TensorFlow.js модель.

## Модель

Используюется CNN модель, решающая задачу регрессии для 3 величин.

Обучение выполнялось на изображениях из датасетов DIV2K и Art Images.

### Описание модели:

| Layer (type) | Output Shape | Param # |
|---|---:|---:|
| input_layer (InputLayer) | (None, 96, 96, 3) | 0 |
| conv2d (Conv2D) | (None, 48, 48, 16) | 448 |
| conv2d_1 (Conv2D) | (None, 24, 24, 24) | 3,480 |
| conv2d_2 (Conv2D) | (None, 12, 12, 32) | 6,944 |
| conv2d_3 (Conv2D) | (None, 6, 6, 48) | 13,872 |
| global_average_pooling2d (GlobalAveragePooling2D) | (None, 48) | 0 |
| dense (Dense) | (None, 48) | 2,352 |
| dense_1 (Dense) | (None, 3) | 147 |
| output_transform (OutputTransform) | (None, 3) | 0 |

В предобработку входит уменьшение изображения до размера 96×96 пикселей.
Так модель становится легче и обучается быстрее, при этом такого количества пикселей достаточно, чтобы правильно оценить яркость, цветность и контрастность.

Модель обучалась на датасетах DIV2K и Art Images, содержащих изображения хорошего качетсва, которые принимались за эталонные.

Во время обучения изображения искусственно искажались случайными изменениями яркости, контрастности и цветности, после чего модель училась предсказывать параметры обратной коррекции.

## Используемые технологии

Основные технологии: TensorFlow.js, Web Worker, Canvas API.

Дополнительно используются `heic2any` и `elheif`.

## Ограничения

Время обработки зависит от размера изображения, браузера и мощности устройства пользователя.

Проект тестировался на изображениях до 15 Мп, обработка занимала до 30 с.
